  Definitions:
    TP (True Positive)  — Line correctly classified as the class
    FP (False Positive) — Line incorrectly classified as the class
    FN (False Negative) — Line of this class missed (classified as other)
    TN (True Negative)  — Line correctly classified as NOT the class
    Precision = TP / (TP + FP)
    Recall    = TP / (TP + FN)
    F1-Score  = 2 * Precision * Recall / (Precision + Recall)
